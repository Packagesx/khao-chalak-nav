แอปนำทางเดินป่าและวิ่งเทรลสำหรับเขาฉลาก จ.ชลบุรี สร้างจากข้อมูล GIS จริง ไม่ใช้พิกัดหรือสถิติที่มโนขึ้นมา วันนี้ยังอยู่ระหว่างพัฒนา แต่เปิดให้ลองใช้และติดตามความคืบหน้าได้แล้ว

ไม่ขายฝัน บอกตรงๆ ว่าตอนนี้ทำอะไรได้จริงบ้าง ส่วนที่เหลือเป็นแผนงานถัดไป (ดูด้านล่าง)

✓

เว็บแอปใช้งานได้จริง

เปิดผ่านเบราว์เซอร์ได้ทันที มีแผนที่พื้นฐานและ backend ที่เชื่อมต่อแล้ว

✓

ติดตั้งเป็นแอปได้ (PWA)

กด "เพิ่มไปยังหน้าจอหลัก" บนมือถือ ได้ไอคอนจริง เปิดเต็มจอเหมือนแอปทั่วไป

✓

ข้อมูลไม่มั่ว

ทุกพิกัด/สถิติที่ยังไม่ผ่านการตรวจสอบจะถูกกำกับไว้ชัดเจนในเอกสารโปรเจกต์ ไม่ใช้ตัวเลขแต่งขึ้น

✓

โค้ดเปิดเผยสาธารณะ

ดูความคืบหน้า และตรวจสอบที่มาของทุกไฟล์ได้บน GitHub ตลอดเวลา

กำลังจะมา

สามฟีเจอร์หลักที่ทำให้เขาฉลากมี "มิติ" ให้เห็นจริง อยู่ระหว่างพัฒนา ยังไม่เปิดใช้งาน

Milestone 10

ภูมิประเทศมีมิติ

มองเห็นสันเขา ความชัน และรูปทรงจริงของภูเขาแบบ 2.5D/3D แทนเส้นคอนทัวร์แบนๆ

Milestone 8-9

จุดนำทางที่แตะได้

แตะจุดบนเส้นทางเพื่อดูระยะ ความชัน และระดับความยากของแต่ละช่วงได้ทันที

Milestone 11

พร้อมใช้แม้ไม่มีสัญญาณ

ดาวน์โหลดพื้นที่ล่วงหน้า แล้วนำทางได้แม้เข้าป่าจนสัญญาณมือถือหายไป

เลือกได้สองแบบ: ติดตั้งเป็นแอป Android หรือเปิดผ่านเว็บเบราว์เซอร์เลยก็ได้

📱 Android APK

⬇ ดาวน์โหลด APK (เร็วๆ นี้)
Android 8.0 ขึ้นไปยังไม่ได้ขึ้น Play Store
  1. กดดาวน์โหลดไฟล์ .apk ด้านบน
  2. เจอข้อความเตือน "แหล่งที่มาที่ไม่รู้จัก" ให้กด "อนุญาต" เฉพาะแอปนี้
  3. กด "ติดตั้ง" แล้วรอสักครู่

🌐 เว็บแอป (ใช้ได้เลยตอนนี้)

เปิด khao-chalak-nav.pack-rezone.workers.dev ↗
ไม่ต้องติดตั้งรองรับทุกเบราว์เซอร์
  1. เปิดลิงก์ในเบราว์เซอร์มือถือหรือคอม
  2. (ไม่บังคับ) กดเมนู → "เพิ่มไปยังหน้าจอหลัก" เพื่อให้เป็นไอคอนแอป
  3. ใช้งานได้ทันที ไม่ต้องมี Play Store
